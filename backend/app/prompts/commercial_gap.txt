Goal:

Rules:
- Only reason from pain points supported by evidence_ids.
- Do not state willingness-to-pay as fact.
- If there is no clear commercial signal, lower confidence.
- If adoption requires rewriting customer architecture, set migration_cost=high and consulting_vs_saas=consulting_like.
- If a wrapper, plugin, dashboard, or hosted layer can solve it, set migration_cost=low or medium.
- Return strict JSON only.
